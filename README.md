# Reserva de Peças

Sistema web front-end desenvolvido como trabalho acadêmico para o gerenciamento e reserva de peças. 

## 🚀 Funcionalidades
- Visualização do catálogo de peças disponíveis.
- Interface para a realização de reservas.
- Layout responsivo para navegação em diferentes dispositivos.

## 🛠️ Tecnologias Utilizadas
- **HTML5 & CSS3:** Estruturação semântica e estilização da interface.
- **JavaScript:** Lógica de interação e manipulação do DOM.
- **Webpack:** Empacotamento de módulos e otimização de arquivos para desenvolvimento e produção.
- **NPM:** Gerenciamento de dependências.
